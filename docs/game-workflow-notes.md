## 一、 今日完成的 6 项核心改造与调优

1. **Fork 仓库并建立 `rebase` 上游同步流**
   - **收益**：既拥有独立的个人定制分支，又能随时通过一条命令无损跟进官方 `nexu-io/open-design` 的最新特性。

2. **启用 `--prod` 本地生产预构建模式**
   - **收益**：获得与打包版一致的秒开速度和低内存占用，同时在源码环境下**物理断路 PostHog 与 Langfuse 遥测（100% 零外发）**，保障企业未公开项目隐私。

3. **净化 UI 顶栏与修复账户显示**
   - **收益**：屏蔽右上角礼盒广告与“升级”按钮（保留 GitHub Star 徽章），修复左下角账户回退显示 `OpenDesign` 的问题，恢复真实头像与昵称。

4. **打通一等公民引擎 `Codebuddy Code (cbc)` 并清理失效模型**
   - **收益**：无需裸 API Key，直接复用企业 CLI 登录态与内网模型额度，完整保留思维链、工具执行树与多轮会话记忆，并清理了已失效的本地自定义模型。

5. **定位并修正 `reasoningEffort: "max"` 慢任务瓶颈**
   - **收益**：将 `~/.codebuddy/settings.json` 与客户端默认推理档位从 `max` 调优为均衡的 `medium`（配合 `deepseek-v4.1-flash` / `claude-sonnet-5.5`），避免单步动辄思考 5~6 分钟，**整体任务提速近 10 倍**。

6. **原生接入火山方舟 `Seedream 5.0 Pro/Flash` 图层拆分管线**
   - **收益**：补齐 `/images/generations` 下的 `image` 参考图、`watermark: false` 去水印、`layer_decomposition: true` 图层拆分及多图层自动落盘（`-layer-1..N.png`），无需外挂转发代理即可在动效任务中一键拆出透明图层素材。

## 二、 对游戏研发的核心价值与可深入方向

1. **AI 原画一键拆图层 + 动效直出（最高价值）**
   - 解决传统 AI 生图“死图一张、需要人工 PS 抠图补底”的痛点，直接将静态 NPC / 横幅拆解为干净底图 + 最多 16 张带透明通道的独立图层，并由 Agent 直接编写 GSAP / Canvas 动效或直出 MP4。

2. **高保真可交互游戏 UI 原型**
   - 相比静态设计稿，可直接挂载真实文件夹（如游戏背包、商店、养成面板），快速生成带真实拖拽、悬浮反馈和状态机的交互原型。

3. **后续高性价比二开方向**
   - **专属游戏 Design System**：在 `design-systems/` 下沉淀游戏专属的稀有度色板、九宫格边框、字体与动效规范；
   - **图层自动裁切与坐标清单**：在拆图层落盘时用内置 `sharp` 自动裁掉四周透明像素并输出 `layers-manifest.json`（含 `x, y, w, h` 坐标），省去临时跑 OpenCV 测量，直接对接客户端引擎；
   - **游戏资产导出 Skill**：定制 `SKILL.md`，让 Agent 自动按 Unity / Cocos 目录结构整理切图并输出动效时间轴参数表。

## 三、 版本管理思考：设计快照 vs Git 代码管理

1. **两套版本逻辑的分工**
   - **探索期（用 OpenDesign 右上角「历史版本 `v1/v2/v3`」）**：宿主在每轮对话结束后**全自动**保存文件快照与可视化缩略图，按“设计意图（Prompt）”定格。无需手动保存，看图即可一键回退，不打断创作心流。
   - **定稿期（用 Git 沉淀入库）**：当设计稿定稿需要进入游戏工程或备份到 GitHub 时，才需要 Git 的工程化管理。

2. **为什么不需要专门开发“Commit & Push”按钮？**
   - 在创作阶段加 Git 按钮反而增加心智负担；
   - 而在定稿需要上库时，由于底层跑的就是拥有完整 Shell 权限的 `Codebuddy Code`，只需挂载「工作目录」或在聊天框直接对 AI 说一句**“这版定稿了，帮我 commit 并 push 到 GitHub 仓库”**，Agent 即可在后台自动完成 Git 版本提交，实现“无感快照探索 + 一句话工程归档”的最佳闭环。
